# MD Shohagh

Personal photo gallery with a private admin panel.

## Features
- Public photo gallery
- Search and category filter
- Full-screen preview
- HD download
- Admin login
- Upload, edit, delete
- Featured photos
- SQLite database
- Local image storage

## Run locally
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
4. Start:
   npm start
5. Open:
   http://localhost:3000

Admin:
- URL: http://localhost:3000/admin
- Username: admin
- Password: change-this-password

IMPORTANT: Change ADMIN_PASSWORD before deploying publicly. For production, set SESSION_SECRET too.
